# palco_landing_page

Single-file, responsive landing page for **Palco Video**, a commercial production house in India with 40 years in media craft (Est. 1985).

## Tech Stack
- Pure HTML5, CSS3, and vanilla JavaScript (Single-file: `index.html`)
- No frameworks or build steps
- Typography: Google Fonts (Bebas Neue, Inter, JetBrains Mono)
- Dark cinematic aesthetic (#111111) with warm amber accent (#E8B04B) and CSS film grain texture
- Mobile-first, fully responsive across 360px, 768px, and 1440px+
- Native `<details>`/`<summary>` accordion for FAQ
- Accessible semantic markup, ARIA attributes, and JSON-LD structured data
